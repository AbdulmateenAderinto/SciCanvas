# Bundled fonts

Web fonts (WOFF2, Latin + Greek subsets, regular / bold / italic / bold italic) from Fontsource (fontsource.org), redistributed under each family's licence. They are embedded into exported SVG, PDF and images so figures look the same on every computer.
